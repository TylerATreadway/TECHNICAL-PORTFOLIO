SSA_Retirement_Calc.PY - SOCIAL SECURITY RETIREMENT BENEFIT EXPLORER
======================================================

OVERVIEW
--------
SSA_Retirement_Calc.py creates an interactive Social Security retirement planning chart
that you can open in a web browser. Enter a date of birth to compare the
percentage of your own full retirement benefit you could receive by
starting benefits at different ages from 62 through 70.

The program generates a standalone HTML file. After it is generated,
you can explore the chart and change the birth date directly in the browser
without running Python again. The generated chart also works offline.

WHAT IT DOES
------------
* Provides a date-of-birth field with a calendar picker.
* Calculates your current age and full retirement age (FRA).
* Shows the earliest potential month for retirement benefits and the
  month when you reach age 70.
* Displays an interactive benefit-percentage chart for claiming ages
  62 through 70, with month-by-month adjustments.
* Lets you drag/select a point on the chart, adjust a slider, or use
  shortcut buttons to compare claiming ages.
* Shows the selected benefit start month and percentage of the full
  retirement-age benefit.
* Optionally accepts your estimated monthly benefit at FRA and shows
  estimated monthly and annual dollar amounts for the selected age.
* Updates immediately when you change the date of birth or benefit amount.

REQUIREMENTS
------------
* Python 3.10 or newer.
* A modern web browser, such as Chrome, Edge, Firefox, or Safari.
* Windows, macOS, or Linux.
* No additional Python packages are required. There is no need to use pip.
* Internet access is not required to use the generated chart.

FILES
-----
SSA_Retirement_Calc.py                         The Python program.

HOW TO RUN IT - WINDOWS
-----------------------
1. Install Python 3.10 or newer from https://www.python.org/downloads/
   if it is not already installed.
2. Save SSA_Retirement_Calc.py in a folder, for example C:\SocialSecurity.
3. Open that folder in File Explorer, click the address bar, type cmd,
   and press Enter. A Command Prompt opens in that folder.
4. Type:

      py SSA_Retirement_Calc.py

   If the 'py' command is unavailable, try:

      python SSA_Retirement_Calc.py

5. The program creates social_security_interactive.html in the same
   folder and attempts to open it in your default browser.
6. If the browser does not open automatically, double-click the
   generated HTML file to open it manually.

HOW TO RUN IT - MAC OR LINUX
----------------------------
1. Ensure Python 3.10 or newer is installed.
2. Open Terminal and change into the folder containing SSA_Retirement_Calc.py.
3. Run:

      python3 SSA_Retirement_Calc.py

4. The HTML file is created in that folder. Open it in a browser if
   it does not open automatically.

USING THE INTERACTIVE CHART
---------------------------
1. Use the calendar/date field to enter your date of birth.
2. Review the displayed current age, FRA, first potential benefit
   month, and age-70 month.
3. Move the claiming-age slider, click/tap the chart, or use a shortcut
   button to see the percentage available at different retirement ages.
4. Optionally enter the monthly Social Security amount you expect to
   receive at FRA, from your Social Security statement. The chart then
   estimates monthly and annual amounts at the selected claiming age.
5. Change the birth date or FRA amount as often as you like. Results
   update inside the browser without rerunning SSA_Retirement_Calc.py.

COMMAND-LINE OPTIONS
--------------------
--birthdate YYYY-MM-DD   Initial date of birth shown in the chart.
                         Default: 1964-09-17.
--benefit AMOUNT         Optional estimated monthly FRA benefit in dollars.
--output FILE            Path/name for the generated HTML file.
                         Default: social_security_interactive.html
                         in the same folder as SSA_Retirement_Calc.py.
--no-open                Create the HTML file without opening a browser.
-h, --help               Show command-line help.

EXAMPLES
--------
Create the chart using the built-in starting values:

    py SSA_Retirement_Calc.py

Start with a birth date of September 17, 1964 and an FRA benefit of $3,000:

    py SSA_Retirement_Calc.py --birthdate 1964-09-17 --benefit 3000

Use another date and benefit amount:

    py SSA_Retirement_Calc.py --birthdate 1958-01-01 --benefit 3100

Save the output with a different filename:

    py SSA_Retirement_Calc.py --output my_retirement_chart.html

Create the chart but do not open the browser automatically:

    py SSA_Retirement_Calc.py --no-open

On macOS or Linux, substitute 'python3' for 'py' in these examples.
Use dates in YYYY-MM-DD format. The program accepts birth dates on or
after January 2, 1933, and does not accept future birth dates.

UNDERSTANDING THE PERCENTAGES
-----------------------------
The chart treats your estimated monthly benefit at full retirement age
(FRA) as 100%.

* Starting before FRA generally reduces your monthly retirement benefit.
* Starting at FRA generally gives you 100% of your FRA benefit.
* Waiting beyond FRA can increase your benefit through delayed retirement
  credits, up to age 70; increases stop at age 70.
* Your exact FRA and percentages depend on your birth date.

For example, if your FRA benefit is $3,000 and the chart shows 80% at a
selected claiming age, the estimated amount is $2,400 per month
($28,800 per year) before other adjustments or deductions.

IMPORTANT LIMITATIONS
---------------------
This is an educational retirement-planning tool, not an official benefit
quote or a Social Security application. It estimates YOUR OWN Social
Security retirement benefit, not spousal, survivor, or disability benefits.

Reaching an eligible age does not by itself establish entitlement. You
also generally need sufficient Social Security work credits (usually 40)
and must apply for benefits. The earnings test can affect payments when
you claim before FRA while still working. Past start dates are comparisons,
not a promise of retroactive benefits. Benefit payments generally arrive
in the month after the benefit month.

Estimates do not account for future cost-of-living adjustments, future
earnings, taxes, Medicare premiums, or all timing rules affecting delayed
retirement credits. For personal benefit estimates and official decisions,
consult your Social Security statement and the Social Security
Administration (SSA).

TROUBLESHOOTING
---------------
'py' or 'python' is not recognized:
    Install Python or check that Python is available on your PATH.
    On Windows, try 'py --version' or 'python --version'.

The chart does not open by itself:
    Open social_security_interactive.html directly in your browser.

The output file cannot be written:
    Check that the destination folder exists and is writable, or specify
    another location with --output.

The calendar is not responding:
    Click the date field or try a different modern browser. You can also
    type the date directly if the browser supports it.

Want to share the chart with someone who does not have Python?
    Give them the generated HTML file. They can open it in a browser
    without installing Python or extra packages.
